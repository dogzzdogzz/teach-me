Serve the repo root (python3 -m http.server 8765), open /tools/sweep.html, then run in the console:

PATHS = await (await fetch('/tools/paths.json')).json();   // or build your own list
await runSweep(PATHS, 'zh');        // [] means clean; repeat with 'en'
await sweepOptions(PATHS.filter(p => p.endsWith('/review.html')), 10);
