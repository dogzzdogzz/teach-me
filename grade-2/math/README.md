# 二年級數學

依台灣 108 課綱整理的國小二年級數學主要學習單元。台北市公立國小均採用此課綱，
實際單元順序與名稱依教科書版本（康軒／南一／翰林）略有差異。

## 主要學習單元

### 數與計算
- **1000 以內的數**：百位的位值、化聚（10 個十是 1 個百）、比大小
- **二、三位數的加減**：直式計算（含進位、退位）、加減驗算
- **九九乘法**：乘法的意義（幾個一數）、2～9 的乘法基本事實、「倍」的概念
- **分裝與平分**：除法的前置經驗（把東西分一分）
- **兩步驟問題**：加減混合的簡單兩步驟文字題

### 量與實測
- **長度**：認識公分（cm）、公尺（m），用尺實測與估測、長度的加減計算
- **容量與重量**：直接比較與間接比較（還沒學標準單位）
- **時間**：報讀幾點幾分、認識日期（年、月、日、星期）、一天的作息時刻

### 空間與形狀
- **平面圖形的構成要素**：邊、頂點、角的初步認識
- **認識三角形、四邊形、圓**
- **立體形體**：面、邊、頂點的直觀觀察

### 關係（代數前置經驗)
- **加減互逆**：用加法檢查減法（以及相反）
- **乘法算式與情境的連結**：把「3 個 5」寫成 5×3

### 資料與統計
- **分類與整理**：把資料分類做成簡單的統計表
