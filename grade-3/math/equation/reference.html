🗂️ 算式填充題速查卡

一張卡把找（　）的方法帶著走 —— 印出來貼在書桌前

什麼是（　）

（　）代表還不知道的數；等號兩邊永遠要一樣多，不是「看到就馬上全部加起來」。

四個逆運算公式（（　）在最前面）

（　）＋ b ＝ c（　）＝ c － b
（　）－ b ＝ c（　）＝ c ＋ b
（　）× b ＝ c（　）＝ c ÷ b
（　）÷ b ＝ c（　）＝ c × b

位置不一樣，公式也不一樣！（易混淆對照表）

算式（　）的位置怎麼算例子
（　）－ b ＝ c被減數（最前面）c ＋ b（　）－3＝5 → 5＋3＝8
a － （　）＝ c減數（中間）a － c8－（　）＝5 → 8－5＝3
（　）÷ b ＝ c被除數（最前面）c × b（　）÷4＝6 → 6×4＝24
a ÷ （　）＝ c除數（中間）a ÷ c24÷（　）＝6 → 24÷6＝4

加法和乘法不用擔心位置：因為 a＋b＝b＋a、a×b＝b×a，（　）在哪裡答案都一樣；只有減法和除法要看清楚（　）在前面還是中間。

驗算三步驟

  1. 把算出來的答案，代回原本（　）的位置。
  2. 照著原本的算式，重新算一次。
  3. 檢查算出來的結果，是不是跟等號右邊的數字一樣 —— 一樣才是對的，不一樣就要重新找。

三個範例

（　）＋9＝15
逆運算：15－9＝6
驗算：6＋9＝15 ✓
8－（　）＝3
（　）在中間：8－3＝5
驗算：8－5＝3 ✓
（　）÷4＝6
逆運算：6×4＝24
驗算：24÷4＝6 ✓
