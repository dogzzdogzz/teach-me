# 三年級數學

依台灣 108 課綱整理的國小三年級數學主要學習單元。台北市公立國小均採用此課綱，
實際單元順序與名稱依教科書版本（康軒／南一／翰林）略有差異。

## 主要學習單元

### 數與計算
- **10000 以內的數**：千位、萬位的位值、化聚、比大小
- **三、四位數的加減**：直式計算與估算
- **乘法**：二、三位數 × 一位數；二位數 × 二位數（直式）
- **除法**：除數是一位數的除法（含有餘數）、乘除互逆、驗算
- **兩步驟問題與併式**：加減乘除混合的兩步驟文字題、初步併式
- **分數**：單位分數與真分數的認識、同分母分數的比較與加減
- **小數**：一位小數的認識、比大小、加減

### 量與實測
- **長度**：認識毫米（mm）、公里（km 依版本），長度的換算與計算
- **重量**：公斤（kg）、公克（g）的認識、實測與計算
- **容量**：公升（L）、毫升（mL）的認識、實測與計算
- **時間**：認識「秒」、時分秒的換算、時間的加減計算

### 空間與形狀
- **角**：角的認識、角的大小直接比較
- **正方形與長方形**：邊與角的性質
- **圓**：圓心、半徑、直徑，用圓規畫圓
- **周長**：周界與周長的概念、正方形長方形的周長計算

### 關係（代數前置經驗)
- **算式填充題**：用（　）代表未知的數
- **乘除互逆**的應用

### 資料與統計
- **報讀表格**：生活中的一維、二維表格
