👨‍👩‍👧 給家長：加減直式這一課

不用會教學法，只要知道孩子卡在哪、怎麼接話

這一課在教什麼

這一課對應 108 課綱三年級「三、四位數的加減：直式計算（含進位、退位）與估算」單元，教孩子用直式算出多位數的加法與減法，並學會用「先估再算」檢查答案是否合理，用加法驗算減法。

大人最容易忽略的重點：退位借過 0 不是「特例」，是這個年段真正的分水嶺。孩子通常很快就學會一般的借位（跟左邊借 1），但遇到像 500 − 236 這種左邊剛好是 0 的情況就會卡住，因為「跟 0 借」感覺上借不到東西。真正的做法是繼續往更左邊找，把中間經過的 0 都變成 9——這一步需要特別花時間帶著孩子一步一步走過，不能只靠多寫幾題練出來。

學會之後孩子應該能做到

  • 算三、四位數加法時，能正確把每一欄的進位加到左邊那一欄，不會漏掉。
  • 遇到退位減法時，能說出「這一欄不夠減，要跟左邊借 1」，並正確把借來的 10 加上去。
  • 遇到要借的那一欄剛好是 0 時，知道要繼續往更左邊找，並把沿路的 0 都變成 9。
  • 算完加減法後，能主動用「先估的答案」或「加回去驗算」來檢查自己的答案有沒有算錯。

在家可以怎麼陪

買東西湊零錢：買東西時故意問「這個 386 元、那個 295 元，兩個一起要多少錢？」讓孩子在生活情境裡練加法進位。
存錢筒倒著算：存錢筒原本有一些錢，孩子拿去買了東西，問「原來有多少、花了多少，還剩多少？」故意選會用到借位的數字（例如原本 500 元）。
先估一估：出門買東西前，先問孩子「大概要準備多少錢？」讓孩子習慣把數字看成整百來估算，而不是每次都要精算才敢下結論。

常見的卡關與怎麼回應

卡關：算 386 + 467 時忘記把個位進位的 1 加到十位，算成 843。

怎麼回應：「個位加起來是 13，只能寫下面那個 3，那多出來的那個 10 跑去哪裡了？」引導孩子發現進位的 1 要送到十位重新加一次，而不是直接說「你漏加了」。

卡關：算 500 − 236 時，看到十位是 0，不知道怎麼借，隨便寫一個答案。

怎麼回應：「十位是 0，0 有東西可以借嗎？那我們再往左邊看看，百位有沒有？」引導孩子發現要往更遠的地方借，並且中間經過的 0 要先變成 9，而不是直接示範答案給他抄。

卡關：算 503 − 268 時，每一欄都直接拿大的數字減小的數字（例如個位算 8 − 3 = 5），得到錯誤答案。

怎麼回應：「題目說的是 503 減 268，所以每一欄都要用上面的數字減下面的數字，不能看哪個數字比較大就先減哪個」提醒孩子減法有固定的順序，不夠減就要借位，不能自己調換順序。

什麼時候可以往下一課

精熟標準：「試題」答對至少 2/3，而且「小遊戲：補上失蹤的數字」有破關（5 關都答對過一次）。如果還沒達到，不用擔心，讓孩子回到「上課」頁面的範例教學區再玩一次，進位與退位的動畫都可以重玩不限次數。
