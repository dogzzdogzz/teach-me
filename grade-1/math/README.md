# 一年級數學

依台灣 108 課綱整理的國小一年級數學主要學習單元。台北市公立國小均採用此課綱，
實際單元順序與名稱依教科書版本（康軒／南一／翰林）略有差異。

## 主要學習單元

### 數與計算
- **100 以內的數**：數數（1 個、2 個、5 個、10 個一數）、認讀與寫數字、個位與十位的位值、比大小、順序（第幾個）
- **分與合**：10 以內數的分解與合成（加減法的基礎）
- **加法與減法**：和在 20 以內的加減基本事實、進位加法與退位減法的初步
- **加減文字題**：合併、添加、拿走、比較等情境問題
- **二位數的加減**：不進位／不退位的直式計算初步（依版本在一下）

### 量與實測
- **長度**：直接比較（比長短）、間接比較、用個別單位（如迴紋針）量長度
- **時間**：報讀時鐘的整點與半點
- **錢幣**：認識 1 元、5 元、10 元、50 元，簡單的換算與付錢

### 空間與形狀
- **立體形體**：直觀分類（像盒子的、像球的、像罐子的）
- **平面圖形**：辨認三角形、正方形、長方形、圓形
- **圖形拼排**：用形狀片拼出圖案、堆疊立體形體

### 關係（代數前置經驗)
- **數的規律**：依規律接續排列（例：2、4、6、⋯⋯）
- **加減互逆的初步經驗**
