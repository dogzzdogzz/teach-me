🗂️ 角度速查卡

度、量角器的兩排數字、量角與畫角的步驟 —— 印出來貼在書桌前

一句話規則

把一整圈平分成 360 等份，一份就是 1 度（1°）。
直角 ＝ 90°；平角 ＝ 180°；一整圈（周角）＝ 360°。

量角器左右兩端各有一個 0，所以有兩排數字。你把哪一端的 0 對準那條邊，就一路讀那一排。
同一格的兩個數字加起來永遠是 180。

量角的三個步驟

  1. 中心點對準頂點：量角器正中央那一點，壓在角的頂點上。
  2. 一端的 0 刻度線對準一條邊：對準右邊那條邊就從右邊的 0 開始，對準左邊那條邊就從左邊的 0 開始。
  3. 看另一條邊穿過哪一格，讀你剛剛開始數的那一排 —— 那個數字就是角度。
0 對準右邊那條邊 → 讀內圈 → 內圈 55、外圈 125 → 這個角是 55° 注意這張圖的直邊躺在一條直線上：從右端的 0 數到那條斜邊是 55°，從左端的 0 數到同一條斜邊是 125°—— 那量的是斜邊和直線另一半之間的角，兩個合起來剛好 180°。所以題目一定要先講清楚 0 對準的是哪一條邊。

畫角的四個步驟

  1. 先畫一條邊，並在它的端點標出頂點。
  2. 擺好量角器：中心點對準頂點，一端的 0 刻度線對準這條邊。
  3. 在要的度數那一格點一個點 —— 讀的是你剛剛開始數的那一排。
  4. 把量角器拿開，從頂點連到那個點，角就畫好了。

四種角的名字

名字 度數的範圍 例子
銳角 大於 0° 而且小於 90° 35°、89°
直角 剛好 90° 90°
鈍角 大於 90° 而且小於 180° 91°、128°
平角 剛好 180°（兩條邊拉成一直線） 180°
89°、90°、91° 是三個不同的名字
「比 90° 大」還不夠 —— 180° 也比 90° 大
角的大小跟邊畫多長沒有關係

轉了幾分之幾圈，就是幾度

一整圈是 360°。平分成幾份，就把 360 除以幾；要幾份，就再乘幾。這一課只算「轉了多少」，不分順時針或逆時針。

轉多少 十二分之一圈 六分之一圈 四分之一圈 三分之一圈 半圈 三分之二圈 四分之三圈 一整圈
幾度 30°60°90°120°180°240°270°360°
360° ÷ 12 ＝ 30° 鐘面一整圈平分成 12 格，所以一格是 30°：時針從 2 走到 6 走了 4 格，4 × 30° ＝ 120°。

合成與分解

兩個角頂點相同、共用一條邊、而且沒有重疊地拼在一起時，合起來的角度就是兩個角度相加；知道合起來是幾度、其中一個是幾度，就用相減找回另一個。

30° ＋ 60° ＝ 90°　／　180° － 115° ＝ 65° 左邊：兩個角拼起來剛好是一個直角。右邊：兩個角拼起來是一個平角，已知一個是 115°，另一個就是 65°。

最容易搞混的三件事

看到這個 很多人會這樣 正確的是
量角器上有兩排數字 隨便挑一排讀，或每次都讀外面那一排 看你把哪一端的 0 對準邊，就從那個 0 一路數下去、讀那一排。（本課圖上的量角器是右端的 0 在內圈、左端的 0 在外圈；真的量角器不一定這樣排，所以要看 0 在哪一端，不是背內外。）讀錯排會得到 180 減掉答案的那個數。
一個明顯比直角小的角，量出來卻是 140° 照著寫下 140° 先用眼睛判斷：銳角一定小於 90°、鈍角一定大於 90°。答案和眼睛看到的不合，就回頭檢查兩件事：量角器有沒有擺好，以及讀的是不是該讀的那一排。這一格兩排寫著 40 和 140，正確答案是 40°。
「比 90° 大的角」 一律叫它鈍角 180° 也比 90° 大，可是它是平角。鈍角要同時滿足兩個條件：大於 90°，而且小於 180°。

這一課的範圍

這一課用的是半圓量角器，一次量得到的角在 0° 到 180° 之間；角的分類也只講到平角 180° 為止，大於 180° 的角（優角）不在這一課。三年級的「角度大搜查」已經教過角是什麼、以及不用度數直接比大小，這一課接著把角變成一個數字。三角形和四邊形的內角和是五年級的單元，這裡也還不碰。
