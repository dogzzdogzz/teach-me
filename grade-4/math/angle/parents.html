👨‍👩‍👧 給家長的一頁：角度與量角器

這一頁是寫給大人看的，不是給孩子看的 —— 陪讀前先花 3 分鐘讀完

1這一課在教什麼

這一課對應 108 課綱四年級「量與實測」的角度單元：認識「度（°）」這個單位、用量角器量角與畫角，以及旋轉角。孩子要學會四件事：說出一整圈是 360°、直角是 90°、平角是 180°；用中心點對頂點、一端的 0 刻度線對準一條邊、看另一條邊穿過哪一格三個步驟量出角度；照四個步驟畫出指定度數的角；以及把兩個角的度數相加或相減。這一課用的是半圓量角器，一次量得到的角在 0° 到 180° 之間，分類也只講到平角 180°，大於 180° 的角（優角）刻意不碰。三年級的「角度大搜查」已經教過角是什麼、怎麼不用度數比大小；三角形的內角和則是五年級的單元。

大人最容易誤解的那一點：大人覺得量角器「就是把它放上去讀數字」，於是孩子讀錯排時只會說「你看錯了」。真正的關鍵是量角器左右兩端各有一個 0，所以有兩排數字，同一格的兩個數字加起來一定是 180。你把哪一端的 0 對準那條邊，就要一路讀那一排——這句話才是規則，「一律讀內圈」或「一律讀外圈」都不是（真的量角器兩排的內外位置不一定一樣）。教孩子一個永遠管用的自我檢查：先用眼睛判斷這個角比直角大還是小，銳角一定小於 90°、鈍角一定大於 90°；數字和眼睛看到的不合，就回頭檢查兩件事：量角器有沒有擺好（中心點對頂點、0 對準邊），以及讀的是不是該讀的那一排。另外還有一個大人自己也會講錯的地方：「比 90° 大的就是鈍角」是錯的——180° 也比 90° 大，可是它是平角。鈍角要同時滿足兩個條件：大於 90°，而且小於 180°。

2學會之後孩子應該能做到

  • 拿到量角器時，會先把中心點壓在頂點上、再把一端的 0 對準一條邊，而不是隨手把量角器擺上去就讀數字。
  • 量一個明顯比直角小的角卻讀到 140° 時，會自己說「不對，銳角一定小於 90°」，先檢查量角器有沒有擺好；擺好了還是不合，就知道是讀錯排，改讀另一排答 40°。
  • 說得出 90° 是直角、180° 是平角、一整圈是 360°，並且知道 91° 和 89° 分別是鈍角和銳角。
  • 兩個角拼成一個平角、其中一個是 115° 時，會直接列出 180° － 115° ＝ 65°。

3在家可以怎麼陪

🚪

門開了多少度

把房門推開，問孩子「你猜這是幾度？」再一起判斷是銳角還是鈍角。重點不是猜準，是讓他習慣先估一個數字再去驗證 —— 這正是量角器讀錯排時唯一能救回來的能力。

🕒

時鐘上的角

看家裡的時鐘，問「時針從 3 走到 6，走過幾度？」引導他想出鐘面平分成 12 格、一格 30°，所以是 3 × 30° ＝ 90°。整點時兩根針的夾角也可以順便問一次。

📄

摺紙做出 90° 和 45°

拿一張紙對摺再對摺，攤開後兩條摺線交出來的角就是 90°；把 90° 那個角再對摺一次就是 45°。讓孩子親手做出這兩個度數，比背下來牢得多。

4常見的卡關與怎麼回應

常見的卡關可以這樣說
讀錯排：一個明顯的銳角，量出來卻寫成 140° 「你先用眼睛看，這個角比直角大還是小？比較小對不對？銳角一定小於 90°，所以 140° 不可能。你剛剛把 0 對準哪一條邊？從那個 0 開始一路數下去，是哪一排？」
量角器沒擺好：中心點沒壓在頂點上，或 0 刻度線沒對準邊 「我們先不要讀數字。第一件事是中心點壓在頂點上，第二件事是把一端的 0 對準其中一條邊。這兩件事都對好了，數字自己就會出來。」
把「比 90° 大的角」通通叫成鈍角，連 180° 也算 「你說 180° 比 90° 大，這句話是對的。那我們看一下 180° 的角長什麼樣子 —— 兩條邊拉成一直線了對不對？那個有自己的名字，叫平角。鈍角要大於 90° 而且小於 180°，兩個條件都要成立。」

5什麼時候可以往下一課

精熟標準：課程頁的試題答對 2/3 以上，而且小遊戲「量角器闖關」有通關，就表示這一課學得差不多了，可以放心往下一課前進。如果還沒達到，鼓勵孩子回到「上課」頁面的範例教學 2 和 3，把五個角和四種畫法都按一次「下一步」走完，看清楚每一步在做什麼 —— 每一次重來都是在把記憶練得更牢。
