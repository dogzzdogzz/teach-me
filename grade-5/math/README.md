# 五年級數學

依台灣 108 課綱整理的國小五年級數學主要學習單元。台北市公立國小均採用此課綱，
實際單元順序與名稱依教科書版本（康軒／南一／翰林）略有差異。

## 主要學習單元

### 數與計算
- **整數四則**：多位數的乘除與四則混合計算、運算律（交換律、結合律、分配律）的應用
- **因數與倍數** ⭐：因數、倍數、公因數、公倍數 —— 本資料夾的兩堂課就在這裡！
- **分數**：擴分、約分、通分，異分母分數的比較與加減
- **分數乘法**：分數 × 整數、分數 × 分數、帶分數的乘法
- **小數**：小數乘法、整數與小數除以整數、分數與小數的互換
- **比率與百分率**：生活中的比率、百分率（%）的認識與應用

### 量與實測
- **面積**：平行四邊形、三角形、梯形的面積公式與應用
- **體積**：立方公分、立方公尺，長方體與正方體的體積公式
- **容積與容量**：容積的概念、毫升與立方公分的關係
- **重量大單位**：公噸
- **時間**：時間量的乘除計算與應用

### 空間與形狀
- **線對稱圖形**：對稱軸、對稱點與對稱邊
- **三角形與四邊形的內角和**
- **多邊形**：正多邊形的認識、扇形的初步認識（圓心角）
- **立體形體**：長方體與正方體的構成要素、展開圖

### 關係（代數前置經驗)
- **用符號代表數**：以甲、乙或 ☐ 列式表示數量關係
- **平均**：平均數的意義與計算

### 資料與統計
- **統計圖表的整理與應用**：生活中較複雜的統計圖表
