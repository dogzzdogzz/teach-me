🎪 柱體錐體俱樂部

認識圓柱、角柱、圓錐、角錐與球，學會數面、稜、頂點

柱體有兩個一樣大又平行的底面，錐體只有一個底面、頂端收成一點：
抓住這個差別，面、稜、頂點的規律就不用死背，用看的就找得到。

今天想怎麼學？（隨時可以換）

範例教學 1

柱體：兩個一樣大的底面

點下面的數字，看看 n 角柱長什麼樣子；點「圓柱」看看柱體也可以有圓形的底面。

形狀面稜頂點

多點幾個不同的數字，規律會自己出現喔！

規律：n 角柱 → 面 = n+2、稜 = 3n、頂點 = 2n

範例教學 2

錐體：一個底面，收成一個頂點

點下面的數字，看看 n 角錐長什麼樣子；點「圓錐」看看錐體也可以有圓形的底面。

形狀面稜頂點

多點幾個不同的數字，規律會自己出現喔！

規律：n 角錐 → 面 = n+1、稜 = 2n、頂點 = n+1

範例教學 3

球：沒有面、稜、頂點，也沒有展開圖

球從每個角度看都是圓的，跟柱體、錐體很不一樣，點按鈕看看為什麼。

球是曲面，沒有平平的面，所以沒有面、沒有稜、也沒有頂點。

不行！展開圖是把平平的面攤開，球整個都是彎的曲面，沒有平面可以攤平 —— 就像你沒辦法把一顆籃球的皮完整攤成一張平的紙一樣。
