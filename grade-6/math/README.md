# 六年級數學

依台灣 108 課綱整理的國小六年級數學主要學習單元。台北市公立國小均採用此課綱，
實際單元順序與名稱依教科書版本（康軒／南一／翰林）略有差異。

## 主要學習單元

### 數與計算
- **質數與合數**：質數的判別、質因數分解（簡單情形）
- **最大公因數與最小公倍數**：短除法、互質，與生活應用
- **分數除法**：分數 ÷ 整數、分數 ÷ 分數，分數四則混合計算
- **小數除法**：除數是小數的除法、小數四則混合計算
- **分數與小數的四則應用**：基準量與比較量的問題
- **比與比值**：比、比值、相等的比、成正比的認識與應用
- **速率**：速率的意義、距離＝速率 × 時間、複合單位（公里／時等）

### 量與實測
- **圓**：圓周率、圓周長、圓面積
- **扇形**：扇形面積（圓心角占圓的幾分之幾）
- **柱體**：角柱與圓柱的體積、表面積

### 空間與形狀
- **放大與縮小**：縮圖與擴圖、比例尺
- **柱體與錐體**：角柱、角錐、圓柱、圓錐的構成要素
- **立體形體的展開圖**

### 關係（代數初步)
- **怎樣解題**：從問題中的數量關係列式
- **未知數**：用 x 等符號列式並求解簡易算式（等量公理的前置經驗）
- **數的規律**：數列與圖形規律的綜合題

### 資料與統計
- **圓形圖**：圓形圖（比例圖）的報讀與繪製
- **統計圖表綜合應用**：解讀生活中的長條圖、折線圖、圓形圖
